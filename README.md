# online-retail-sales-and-customer-insights-dashboard


📌 Project Overview

The Online Retail Sales & Customer Insights Dashboard is an interactive Power BI dashboard developed to analyze retail sales performance, customer behavior, product performance, and operational metrics. The project uses MySQL for data storage and querying, SQL for analysis and data cleaning, and Power BI for visualization.

The dashboard enables users to monitor key performance indicators (KPIs), identify sales trends, analyze payment preferences, evaluate return requests, and compare revenue across products and store locations.


🎯 Project Objectives

- Analyze total revenue generated from retail transactions.
- Identify the best-performing products based on revenue.
- Understand customer payment preferences.
- Monitor product return requests.
- Track revenue across different store locations.
- Filter data using delivery status.
- Build an interactive dashboard for business decision-making.

🧹 Data Cleaning

🗄️ SQL Analysis

The following SQL queries were used during analysis:

1. SELECT ROUND(SUM(revenue_generated),2) AS Total_Revenue
FROM updated_data1;

2. SELECT payment_method,
COUNT(transaction_id) AS Total_Transactions
FROM updated_data1
GROUP BY payment_method;

3. SELECT product_name,
ROUND(SUM(revenue_generated),2) AS Revenue
FROM updated_data1
GROUP BY product_name
ORDER BY Revenue DESC;

4. SELECT return_requested,
COUNT(transaction_id) AS Total_Returns
FROM updated_data1
GROUP BY return_requested;

5. SELECT store_location,
ROUND(SUM(revenue_generated),2) AS Revenue
FROM updated_data1
GROUP BY store_location
ORDER BY Revenue DESC;


🔍 Key Insights

- The business generated approximately 1.78M in total revenue.
- Multiple payment methods are supported, with one method accounting for the largest share of transactions.
- Product revenue varies significantly, helping identify top-selling products.
- Around one-third of transactions include return requests, indicating an opportunity to investigate return causes.
- Revenue is distributed across multiple store locations, enabling regional performance comparisons.
- Delivery status filters allow focused operational analysis.
